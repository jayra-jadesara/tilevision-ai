# What's new in TileVision AI 1.2.43

**Faster, safer, clearer**

- Rebuilding the search index is much faster when the same photo appears in several folders — identical files are analysed once (#99).
- Your catalogue database is properly encrypted when you close the app (#100).
- Description search: clearer match percentages, colour-aware results, and a clearer message if the one-time model download fails offline (#98, #100).
- Search results list each tile once and show how many copies you have (for example “+2 copies”) (#98).
- Export Catalogue: one card per tile (extra copies listed under “Also at”), select several results at once, much smaller PDFs, and the app stays responsive while exporting (#102).
- New Activity log — your actions are recorded in the log file and on the Activity page (#103).
- New Help page with 12 steps and up-to-date screenshots for light and dark themes (#104).
- Smaller polish: quieter logs, a clearer search-stall message, and the Cancel button no longer reports a false warning (#100, #101).
